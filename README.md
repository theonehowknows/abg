**ABG** is a reading companion designed specifically for individuals with dyslexia and visual sensitivity. By combining specialized dyslexia-friendly typography, customizable high-contrast color overlays, and eye-strain-reducing background tints, ABG creates a comfortable, fatigue-free reading environment tailored to each reader's visual comfort.

## Key Features

* **Dyslexia-Friendly Typography**: Built-in support for specialized typefaces (e.g., OpenDyslexic, Lexend) with enhanced letter-spacing, line-height, and paragraph padding to prevent letter crowding and visual drifting.
* **Custom Color Filters & Overlays**: Choose from clinically recommended tint presets (yellow, blue, peach, mint, rose) or adjust hue, saturation, and opacity via a custom color slider to mitigate symptoms of Visual Stress (Meares-Irlen Syndrome).
* **Eye-Strain Reduction**: Soft-contrast reading modes (warm sepia, muted dark mode, low-glare paper mode) engineered to eliminate harsh contrast and screen flicker fatigue.
* **Reading Focus Guides**: Optional horizontal line overlays and focus rulers to help readers track text line-by-line without losing their place.
* **Text Customization**: Quick sliders for font size, word spacing, and line spacing for immediate readability improvements.
